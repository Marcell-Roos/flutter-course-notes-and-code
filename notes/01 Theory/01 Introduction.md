
# What is Flutter
Flutter is a framework for Dart to develop multi-platform app.
- Flutter = Engine
- Dart = Language

# Flutter Commands
Create a new flutter app from CLI
`flutter create {app_name}`

This will create the "Hello World" type app for Flutter

Run flutter from terminal

`flutter run lib/main.dart`

with hot reload

````
flutter run -t lib/main.dart
````
